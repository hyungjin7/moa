# 문서 편집과 이전 버전 복원

관리자로 로그인한 뒤 문서를 열고 상단 **편집**을 누르세요.

| 하고 싶은 일 | 방법 |
| --- | --- |
| 내용 수정 | 왼쪽 원문에서 Markdown을 수정합니다. |
| 결과 확인 | 나란히 보기 또는 미리보기를 누릅니다. |
| 저장 | 저장 버튼 또는 Cmd/Ctrl+S를 누릅니다. |
| 이전 내용 확인 | 이전 버전에서 저장 시각과 작성자를 보고 선택합니다. |
| 되돌리기 | 원문을 확인하고 이 버전으로 복원 → 복원 실행을 누릅니다. |
| 복원 취소 | 다시 이전 버전을 열어 복원 직전 내용을 선택합니다. |

복원할 때도 현재 저장된 내용이 보관됩니다. 아직 저장하지 않은 편집 내용은 복원 전에 따로 복사해 두세요.

## 알아두세요

- 기존 문서의 맨 위 `export const title`, `group`, `date`는 제목·분류·날짜입니다. Markdown 본문과 기존 MDX 컴포넌트를 함께 유지할 수 있습니다.
- 문법 오류가 있으면 저장하지 않습니다. 다른 곳에서 문서가 바뀌면 덮어쓰지 않고 안내합니다. 이때 작성한 내용을 복사한 뒤 최신 문서를 다시 열어 합쳐 주세요.
- 최근 50개 버전을 보관합니다. 문서 하나의 원문은 최대 512KiB입니다.
- 관리자만 편집할 수 있습니다. 일반 회원과 외부 공유 링크는 읽기 권한을 유지합니다.
- 이전 버전은 같은 저장소에 보관되므로 별도 백업도 필요합니다.
