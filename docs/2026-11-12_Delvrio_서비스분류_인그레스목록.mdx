## 따로 기억할 사항

- **MOA**: `moa` namespace의 `moa` 인그레스가 `moa:5001`로 전달합니다. 원소스는 `ruucm/moa`, 우리가 수정하는 저장소는 `hyungjin7/moa`입니다.
- **Suntax**: K3s 안에서 Suntax 앱을 실행하는 것이 아닙니다. `bbb-namespace/suntax-ingress`가 별도 서버 `116.43.234.73:80`으로 넘겨줍니다.
- **oMLX**: `192.168.219.48`의 LLM 서버로 전달하고 로그인은 BBB 경로를 사용합니다.
- **Argo CD**: 같은 namespace·도메인·기본 경로·서비스를 가리키는 인그레스가 두 개 있습니다. 중복 후보이며 이번 목록 작성에서는 변경하지 않았습니다.
- **홈페이지**: `www`와 `bbb-namespace`에 같은 호스트 설정이 공존합니다. 단순히 이름이 비슷하다는 이유만으로 삭제하면 안 됩니다.
- **MCP Gateway**: 인그레스 Class는 nginx이고 ADDRESS가 비어 있습니다. 실제 연결 정상 여부와 프로그램 원소스는 추가 확인이 필요합니다.
- 이 목록은 인그레스가 있는 서비스만 다룹니다. DB·스토리지·내부 전용 서비스까지 모두 나열한 자산 목록은 아닙니다. 인그레스 설정 존재는 접속 정상 검증과 다릅니다.
