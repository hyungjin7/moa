# 글 이동·삭제·휴지통

관리자로 로그인하면 글 상단에 **이동 · 삭제 · 휴지통**이 보입니다. 일반 회원에게는 보이지 않습니다.

## 글 이동

1. 글을 열고 **이동**을 누릅니다.
2. 같은 프로젝트라면 옮길 그룹을 선택하거나 새 그룹 이름을 입력합니다.
3. 다른 프로젝트를 고르면 본문과 이전 버전이 함께 이동합니다. 그 프로젝트 회원이 글을 볼 수 있게 됩니다.
4. 같은 이름의 글이 있으면 덮어쓰지 않습니다. 상대 경로의 첨부 컴포넌트가 깨지는 경우에도 원래 글을 유지합니다.

## 글 삭제와 복원

1. **삭제 → 휴지통으로 이동**을 누르면 목록과 검색에서 글이 빠집니다.
2. 글 상단 또는 프로젝트 홈의 **휴지통**을 누릅니다.
3. 해당 글의 **복원**을 누르면 원래 프로젝트·그룹으로 돌아옵니다. 이전 버전도 유지됩니다.
4. 원래 위치에 같은 이름의 글이 있으면 덮어쓰지 않고 알려줍니다.

휴지통은 보관함이므로 자동으로 영구 삭제하지 않습니다. 프로젝트의 마지막 글을 삭제해도 홈의 휴지통에서 복원할 수 있습니다.

## 공유 링크

다른 프로젝트로 이동하거나 삭제하면 기존 공유 링크는 해제됩니다. 복원해도 옛 공유 링크는 살아나지 않습니다. 다시 공유하려면 새 링크를 만드세요. 글 이동 후 주소도 바뀌므로 필요한 경우 새 주소를 다시 고정합니다.
