## 사용자 확인 필요

운영 Keycloak 버튼에서 `Client not found`가 표시됐다. 요청 Realm/Client ID는 `delvrio-internal`/`moa-web`이다. 관리자가 같은 Realm에 클라이언트를 등록하고 Secret을 다시 입력한 뒤 실제 사용자 인증·승인·재로그인을 검증해야 한다. 이 검증 전에는 실사용 SSO 로그인이 완료됐다고 보고하지 않는다.

Owner 초기 비밀번호의 Mac 복사는 자동 승인 심사에서 거절되어 수행하지 않았다. 대신 비밀을 내보내지 않는 `scripts/set-k3s-owner-password.py`를 제공했다. 사용자가 직접 선택한 비밀번호의 해시만 SSH stdin으로 전송한다.

GitHub checks는 `npm ci`, OIDC 보안 테스트, 프로덕션 빌드를 수행한다. Git push 기반 K3s 자동 배포는 구성하지 않았으며 이번 배포는 검증된 digest로 직접 적용했다.

## 최초 관리자 설정 후속 확인

사용자가 자체 Owner 비밀번호 설정을 완료했다. 초기 무작위 비밀번호와 다르게 변경됐고, 실행 Pod의 비밀번호 해시가 현재 moa-auth와 일치함을 값 출력 없이 확인했다. Mac 기본 Python의 scrypt 미지원 문제는 Node crypto로 해시를 생성하도록 수정하고 합성 값으로 검사했다.
